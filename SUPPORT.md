# Getting help

- Problem, idea or translation fix: open an issue and pick a form.
- Taskbar missing or stuck: press Ctrl+Alt+Win+K, or run `katofli.exe --restore-shell` from the folder Katofli is installed in.
- Security problem: see SECURITY.md. Do not open an issue.

Look through any log before you attach it. It can contain device names and web addresses.
